FreqBlog API (Song Info)

Used by the Song Info (BPM/Key) widget. Stored locally in the database and never sent to the browser.

Last.fm scrobbling

Scrobbles local MP3s played in the integrated player. Tracks need ID3 artist, title and album, and must be at least 2:00 long. Short practice loops are never scrobbled. Create an API account at last.fm/api/account/create. The API secret and session key are stored in the local database and never returned to the browser.

About v1.0

A personal practice companion to organize your daily guitar routine. It combines a step-by-step practice assistant with a countdown timer, a metronome, a drum machine and your backing tracks & resources — all in one place.

  • Practice Assistant — guided routine with a per-exercise timer, progress bar, and an end-of-time chime + flash.
  • Sections — tools, rhythm, backing tracks and notes, fully editable from this Manager.
  • Widgets — metronome, drum machine, quick notes, delay calculator and a fretboard trainer (identify / locate notes).

Technologies

  • Frontend: HTML5, CSS3 and vanilla JavaScript (no frameworks). All sound is synthesized with the Web Audio API.
  • Backend: Python (standard library http.server) exposing a small local REST API.
  • Database: SQLite (routines, sections, items and settings).
