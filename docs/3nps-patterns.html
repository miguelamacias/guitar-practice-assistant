3NPS modes: mode tonic vs parent major

The same seven 3NPS shapes can be numbered in two ways. Choose a mode and compare from the mode tonic against from the parent major. In both groups, the mode root is green and the other scale notes are amber.

mode root other mode notes 17-fret board · 0–17
Option A

From the mode tonic

P1 starts on the mode tonic. Patterns are numbered by mode degree: for A Aeolian, P1 starts on A, P2 on B, P3 on C, and so on.

Option B

From the parent major

P1 starts on the parent major tonic. These are the standard major-scale patterns; the mode tonic is highlighted green but appears wherever it falls in the parent major. For A Aeolian, parent P1 starts on C and the A root is in P6.

Reading the comparison: every card must contain 18 notes, exactly 3 per string, all belonging to the selected mode. A card can contain notes outside the green root, but no note outside the mode.

Shape relationship: the two groups contain the same seven shapes. Only the numbering and the starting point change. Mode-tonic P1 is the same shape as the parent-major pattern that begins on the mode root.

Board fit: the check uses fret 0–17, matching the current Theory board. All seven church modes and all twelve roots were checked for the 17-fret limit.
